# Storage Provider Options - Development Guide

## Overview
The application now supports **three storage provider modes** for development, allowing you to choose based on your needs:

## 1. **Disabled Storage** (Fastest for Testing)
- **Use Case**: When you don't care about actual file storage
- **Environment Variable**: `STORAGE_DISABLED=true`
- **Behavior**: Storage initialization is skipped entirely
- **Pros**: Minimal setup, fastest startup
- **Cons**: No actual file storage

```bash
export STORAGE_DISABLED=true
go run cmd/api/main.go
```

## 2. **No-Op Storage** (Mock URLs)
- **Use Case**: Testing API responses without actual storage
- **Environment Variable**: `STORAGE_PROVIDER=noop`
- **Behavior**: Returns mock URLs (`https://mock-storage.local/...`) without storing anything
- **Pros**: Simple setup, generates valid URLs for testing frontend
- **Cons**: URLs don't actually serve files

```bash
export STORAGE_PROVIDER=noop
go run cmd/api/main.go
```

## 3. **Filesystem Storage** (Local Development)
- **Use Case**: Full local development with real file storage
- **Environment Variable**: `STORAGE_PROVIDER=filesystem`
- **Base Directory**: `FILESYSTEM_BASE_DIR=./storage` (default)
- **Behavior**: Stores files locally on disk, returns `file://` URLs
- **Pros**: Real files on disk, can inspect/debug, no external services needed
- **Cons**: URLs won't work in browser (need special handling)

```bash
export STORAGE_PROVIDER=filesystem
export FILESYSTEM_BASE_DIR=./storage
go run cmd/api/main.go
```

## 4. **MinIO/S3** (Full S3-Compatible)
- **Use Case**: Production-like development
- **Environment Variable**: `STORAGE_PROVIDER=minio`
- **Additional Configuration**:
  - `S3_ENDPOINT=localhost:9000` (MinIO local)
  - `S3_ACCESS_KEY=minioadmin`
  - `S3_SECRET_KEY=minioadmin`
  - `S3_BUCKET=ai-day`
  - `S3_REGION=us-east-1`
  - `S3_USE_SSL=false` (for local MinIO)
- **Behavior**: Connects to MinIO/S3, generates presigned URLs
- **Pros**: Production-ready, presigned URLs work in browser
- **Cons**: Requires MinIO/S3 running (docker-compose)

```bash
export STORAGE_PROVIDER=minio
export S3_ENDPOINT=localhost:9000
docker-compose up -d minio postgres redis
go run cmd/api/main.go
```

## Quick Start Examples

### Minimal Development (No Storage Needed)
```bash
export STORAGE_DISABLED=true
go run cmd/api/main.go
```

### With Mock URLs (Test Frontend)
```bash
export STORAGE_PROVIDER=noop
go run cmd/api/main.go
```

### With Local Filesystem (Debug Files)
```bash
export STORAGE_PROVIDER=filesystem
mkdir -p ./storage
go run cmd/api/main.go
```

### Full Setup with MinIO
```bash
# Start infrastructure
docker-compose up -d postgres redis minio

# Run API (defaults to minio)
go run cmd/api/main.go

# Run worker
go run cmd/worker/main.go
```

## Configuration Reference

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `STORAGE_DISABLED` | bool | `false` | Disable storage entirely |
| `STORAGE_PROVIDER` | string | `minio` | Provider type: `disabled`, `noop`, `filesystem`, `minio`, `s3` |
| `FILESYSTEM_BASE_DIR` | string | `./storage` | Base directory for filesystem provider |
| `S3_ENDPOINT` | string | `localhost:9000` | MinIO/S3 endpoint |
| `S3_ACCESS_KEY` | string | `minioadmin` | MinIO/S3 access key |
| `S3_SECRET_KEY` | string | `minioadmin` | MinIO/S3 secret key |
| `S3_BUCKET` | string | `ai-day` | Bucket name |
| `S3_REGION` | string | `us-east-1` | AWS region (for S3) |
| `S3_USE_SSL` | bool | `false` | Use SSL/TLS (for S3 production) |

## Implementation Details

### File Locations
- **Noop Provider**: `internal/storage/noop.go`
- **Filesystem Provider**: `internal/storage/filesystem.go`
- **MinIO Provider**: `internal/storage/minio.go` (existing)

### All Providers Implement
```go
type Provider interface {
    PresignUpload(ctx context.Context, objectKey, contentType string, duration int64) (string, error)
    PresignDownload(ctx context.Context, objectKey string) (string, error)
    Delete(ctx context.Context, objectKey string) error
}
```

## Testing Recommendations

**Unit Testing**: Use `noop` provider
```bash
STORAGE_PROVIDER=noop go test ./...
```

**Local Integration**: Use `filesystem` provider
```bash
STORAGE_PROVIDER=filesystem go run cmd/api/main.go
```

**Production Testing**: Use `minio` provider
```bash
STORAGE_PROVIDER=minio go run cmd/api/main.go
```
